## Что нужно, чтобы довести этапы 🟡 до ✅

1. **Мод.** Собрать `client-mod` с доступом к maven.neoforged.net и исправить ошибки компиляции, если NeoForge/Minecraft API отличается от ожидаемого. Места с риском:
   - пакет `OptionsScreen` (в 1.21 — `screens.options`);
   - сигнатура `ConnectScreen.startConnecting`;
   - направление поворота головы (константа `LOOK_SIGN` в `PlayerModelRenderer`).
2. **Вход Microsoft.** Зарегистрировать Azure App ID и получить одобрение Mojang. Без этого вход не пройдёт даже при правильном коде.
3. **Живая установка.** Запустить лаунчер на чистой машине и проверить полную цепочку: Java → 1.21.1 → NeoForge → сборка → запуск.
4. **Арт.** Нужны скриншоты локации для панорамы (ресурспак Rift UI), финальный логотип в PNG и иконка приложения.

## Не реализовано

- Автообновление самого лаунчера: нужен сервер релизов, например `electron-updater` + GitHub Releases. Будет отдельным этапом.
- Расписание бэкапов внутри панели. Сейчас есть ручной запуск и systemd-таймер для `backup.sh`.
- Загрузка сборки с несколькими вариантами одного мода для разных ОС: не потребовалась.
