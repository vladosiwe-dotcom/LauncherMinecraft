# Сквозной тест (end-to-end)

Задание `end-to-end` в `.github/workflows/build.yml` проходит путь игрока на настоящем сервере и клиенте:
меню → «Войти в разлом» → полёт в разлом → мир → окно Системы → выход.

- `fetch_mods.py` скачивает с Modrinth моды для теста (Create, Epic Fight, Iron's Spells и их зависимости).
- `server.properties`, `options.txt` — настройки сервера и клиента для теста.
- Клиент запускается с `RIFT_E2E=1` (сценарий `client-mod/.../dev/EndToEndTest.java`) и `SOLO_E2E_SHOTS=1`.
  Второй флаг включает в Solo Status кадры сцены пробуждения, которая играет при первом входе.

Скриншоты (шаги теста и кадры пробуждения, уменьшенные до 640×360) после каждого прогона публикуются в ветку
`e2e-frames`. Ветка перезаписывается каждым прогоном. Посмотреть: `git fetch origin e2e-frames && git checkout FETCH_HEAD -- .`
во временной папке. Полные логи и скриншоты лежат в артефакте `end-to-end` прогона.
